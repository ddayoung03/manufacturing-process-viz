# 공정 단면 시뮬레이터

기계공작법 과제 (AI 활용 웹 SW 작성). 서로 다른 세 공정을 단계별로 조작하며 교재 공식으로 계산하고, 단계마다 교재 근거와 현상·핵심 변수·가정·한계를 함께 보여 주는 브라우저용 인터랙티브 시각화.

교재: M. P. Groover, *Introduction to Manufacturing Processes*, Wiley, 2012. 쪽 번호는 교재에 인쇄된 쪽이다 (PDF 쪽 = 인쇄 쪽 + 16).

## 검증·오류 처리 (화면 경고)

| 상황 | 표시 |
|---|---|
| 라이저 높이 D > h + t/2 (막힌 라이저가 주형 밖으로 나감) | 기하학적으로 불가능 → 슬라이더 최대값을 h + t/2 로 막음. h·t 를 줄이면 D 도 함께 줄어듦 |
| 라이저가 주물보다 먼저 굳음 (T_TS 비 ≤ 1) | 빨간 경고, 수축공을 주물 안에 그림, 필요한 최소 D 제시 |
| 압출 헤드 압력 p > pmax (Qx < 0) | 빨간 경고: 압출 불가 |
| 체 철사 굵기 ≥ 눈 간격 (PS ≤ 0) | 빨간 경고: 구멍 없음 |
| 겉보기 밀도 > 진밀도 (충전율 > 1) | 빨간 경고 |
| 부싱 안지름 ≥ 바깥지름 | 빨간 경고 |
| 소결 온도 ≥ 녹는점 | 빨간 경고: 고상 소결 아님 |
| 교재 권장 범위 밖 (채움 20–40%, 0.7–0.9 Tm, 충전율 0.5–0.7, 70–700 MPa, 450 kN 프레스 등) | 노란 경고 |

## 단위

화면 단위는 각 슬라이더와 결과 옆에 적었다. 계산 내부 단위는 교재 식을 따른다.

- 주조: cm, cm², cm³, s, min (g = 981 cm/s²)
- 압출: SI (m, rev/s, Pa, Pa·s) 로 계산하고 mm, rev/min, MPa, cm³/s 로 표시
- 분말: in (체), µm, g/cm³, mm², MPa, kN (1 t = 9.81 kN), °C (T/Tm 은 절대 온도)

## 한계

- 모든 계산은 교재의 단순화 모델이다. 가정과 한계는 단계마다 오른쪽 패널에 적었다.
- 주조: 마찰 없는 주입, 직사각 판 주물, 원통 라이저 (D = H). 응고층 두께 ∝ √t 는 시각화용 가정이다.
- 압출: 평판 근사, 점도 일정, 누설 유동 무시. 다이 스웰 비 rs 는 교재 값이 없어 직접 입력한다.
- 분말: 블렌딩은 교재에 식이 없어 정성적으로만 보여 준다. 밀도-압력 곡선, 냉각 곡선, 소결 사이클의 온도축은 정성적이다.
- 그림의 수축량 등은 보이도록 과장한 부분이 있으며, 그림 안에 그렇게 적어 두었다.
